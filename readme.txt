A complete and lightweight SEO plugin: metadata, per-page SEO indicator, indexing, structured data, redirections and 404 log.

== Description ==

EO SEO covers every important part of SEO without turning into a maze of settings. It relies on the WordPress APIs first (document title, robots, canonical, native sitemaps, virtual robots.txt) and adds nothing to the front but the tags search engines read: no script, no style.

= Metadata =

* SEO title, meta description, focus keyphrase, noindex, canonical URL and social sharing (Open Graph, X cards) for every content and term.
* Title and description templates per post type, taxonomy and archive, with variables (%title%, %sitename%, %sep%, %excerpt%, %term%, %page%…).
* Default sharing image.
* An "EO SEO" panel in the block editor with a Google preview and character counters.

= Per-page SEO indicator =

A red, orange or green badge in the editor and in the content lists ("9/12 points OK"), with the points to fix: title and description (length, duplicates), focus keyphrase (title, address, introduction, competing pages), content length, headings, alternative texts, internal links, orphan pages, broken internal links, and a light readability review valid in every language (long sentences and paragraphs, text without subheadings).

= Indexing =

* Choose which post types and taxonomies search engines see; it drives noindex and the sitemap.
* WordPress sitemap without noindex contents, with the date of last modification.
* Virtual robots.txt rules. No file is ever written on the server.
* Internal search and date archives in noindex, attachment pages redirected to the file, optional cleanup of the head and feeds.
* Google Search Console and Bing verification.

= Structured data =

One JSON-LD graph: website, organization, local business or person (logo, address, phone, social profiles), web page, article and breadcrumbs. A "Breadcrumbs" block is included. Developers can extend the graph with the `eo_seo_schema_graph` filter.

= Redirections and 404 errors =

* 301, 302 and 410 redirections, created by hand, from the 404 log or by CSV import (the key tool of a redesign).
* No redirection chains.
* Automatic redirection when the address of a published content changes, sub-pages included.
* 404 log with one row per address, without any IP address; vulnerability probes are filtered out.

= Dashboard =

A review of the whole site with a link to fix each point.

= Works with EO Tools =

EO SEO registers abilities (WordPress Abilities API) that the AI connected to EO Tools uses to audit the site and propose changes. The AI never changes the live site: its proposals are applied by a person.

= Other SEO plugins =

When Yoast SEO, SEOKEY, Rank Math, SEOPress, All in One SEO or The SEO Framework is active, EO SEO outputs nothing on the front and hides its editor panel to avoid duplicates. Redirections and the 404 log keep working.

= Privacy =

EO SEO makes no request to any external service and stores no IP address.

== Installation ==

1. Install and activate the plugin.
2. Open EO SEO › Dashboard and follow the points to fix.
3. Review the templates in EO SEO › Settings.

== Frequently Asked Questions ==

= Does EO SEO write a robots.txt or .htaccess file? =

No. robots.txt stays virtual, generated by WordPress. If a physical robots.txt file exists, the dashboard reports it.

= What happens to my data when I delete the plugin? =

It is kept, unless you check "Delete all EO SEO data" in EO SEO › Settings › Tools.
